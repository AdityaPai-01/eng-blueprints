# File Manager CLI Application

A lightweight Command-Line Interface (CLI) file manager built with Python. It provides basic filesystem navigation and file/folder management operations through a simple command-based interface.

---

## Features

* **List Directory (`ls`)**: Display files and folders in the current directory.
* **Change Directory (`cd`)**: Navigate between directories.
* **Create File (`touch`)**: Create a new file.
* **Create Directory (`mkdir`)**: Create a new folder.
* **Rename (`rn`)**: Rename files or folders.
* **Copy (`cp`)**: Copy files or folders to another location.
* **Move (`mv`)**: Move files or folders to another location.
* **Delete (`rm`)**: Delete files or folders.
* **File Information (`info`)**: Display basic information about a file or folder.
* **Search (`find`)**: Search for files and folders within a directory.
